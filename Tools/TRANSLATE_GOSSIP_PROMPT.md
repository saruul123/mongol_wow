Чи WoW 3.3.5a NPC-ийн мэндчилгээ/gossip текстийг англиас Монгол (кирилл) хэл рүү орчуулагч.
Оролт: /home/saruul/Pictures/World of Warcraft 3.3.5a/Interface/AddOns/MongolWoW/Tools/gossip_en.json = [{id,k,e}] (k="t" NPC-ийн ярианы текст, k="o" цэсийн сонголтын богино мөр). 297 мөр.
Гаралт: Tools/gossip_mn.json = [{id,m}] (ижил id, m = орчуулга, ensure_ascii=False). Бүх мөрийг орчуул.
Дүрэм:
- `$N $n $C $c $R $r $B $b` болон `$g<эр>:<эм>;` placeholder-ыг ЯГ хэвээр (тоо, дараалал). `$B` ард кирилл үсэг зайгүй залгана.
- NPC/газар/эд зүйл/ур чадвар/фракцын нэр (Horde, Alliance, Orgrimmar, Durotar, Razor Hill, Lok'tar ogar гэх мэт ухагдахуун/мэндчилгээ) англиар үлдээ. Монгол нөхцөл зураасаар (`Orgrimmar-т`). Нэг үгэнд латин+кирилл холихгүй (нөхцөлөөс бусад).
- `<NPC үйлдэл>`-ийн хаалт хадгал. "k":"o" мөр нь цэсийн сонголт тул богино, шууд орчуул ("I want to train" -> "Би сурахыг хүсэж байна" гэх мэт, "Bind"/"Train me" шиг тохиромжтой богино хэлбэр).
- Зохиомол, амьд, товчлохгүй, хасахгүй.
Урсгал: gossip_en.json-г Read хийж, орчуулгыг Python/heredoc-оор JSON болгож бич (хэсэг хэсгээр бичиж болно). Дараа нь `python3 -I Tools/gossip_check.py` ажиллуул; алдаа гарвал засаж 0 алдаа хүртэл. Бусад файлыг БҮҮ өөрчил.
Дууссаны дараа нэг мөр: "gossip: N мөр, 0 алдаа".
